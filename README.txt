SPELLSYNC - SINGLE FILE EDITION

Run the app:
  python SpellSync.py
or on Windows:
  py SpellSync.py

The main interface and learning games use Python's standard library (Tkinter).
Optional features:
- Online grammar suggestions: requests + internet access
- Translation: deep-translator + internet access
- PDF text extraction: pypdf
- Read aloud: pyttsx3 and a working system speech engine
- Voice input: SpeechRecognition, PyAudio, microphone, and internet access

Optional installs (only if allowed and needed):
  python -m pip install requests deep-translator pypdf pyttsx3 SpeechRecognition pyaudio

Note: no app can guarantee microphone/audio packages are available on a restricted school PC.
